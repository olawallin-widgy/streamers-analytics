## HIGH Bugs

### BUG-1 — Token Packages page is 404
**Pages:** `/tokens`, `/tokens/purchase`  
**Devices:** All (Chromium + Firefox)  
**Detail:** Members cannot buy tokens. Both the token packages listing and the purchase flow return 404. This is a critical blocker for monetisation.

**How to reproduce:**
1. Log in as member on sexystreamers.com
2. Navigate to `/tokens`
3. Observe: 404 page

---

### BUG-2 — Account Settings page is 404
**Pages:** `/account`  
**Devices:** All (Chromium + Firefox)  
**Detail:** Members cannot access their account settings. Page returns 404 after login.

**How to reproduce:**
1. Log in as member on sexystreamers.com
2. Navigate to `/account`
3. Observe: 404 page

### BUG-3 — Streamer app `loggedIn` JS error (still unresolved from previous test)
**Pages:** Dashboard, Messaging, Clients, Finance, Account — all pages on app.sexystreamers.com  
**Devices:** Samsung Galaxy S23, Desktop Chrome  
**Error:** `TypeError: Cannot read properties of undefined (reading 'loggedIn') at https://app.sexystreamers.com/_nuxt/8137ae3.js`  
**Detail:** This error was found in the previous QA test and has not been fixed. Fires on every streamer page.

---

### BUG-4 — Streamer app 429 Rate Limiting
**Pages:** Streamer Profile, Shows, Messaging, Finance, Clients, Onboarding  
**Devices:** Samsung Galaxy S23, Desktop Chrome  
**Error:** `Failed to load resource: the server responded with a status of 429`  
**Detail:** API endpoints on the streamer app return 429 Too Many Requests during normal page navigation. Likely an overly aggressive rate limit on the backend.

---

### BUG-5 — WebKit 401 Unauthorized on key pages (Safari-specific)
**Pages:** `/performers`, `/register`, `/login`  
**Devices:** iPhone 14 Pro, iPad, Desktop Safari (WebKit only — not reproducible on Chrome/Firefox)  
**Error:** `Failed to load resource: the server responded with a status of 401 (Unauthorized)`  
**Detail:** These pages return 401 errors only in WebKit-based browsers. Likely a CORS or cookie/credential policy issue specific to Safari.

---

### BUG-6 — Firefox: JS errors on all logged-in pages
**Pages:** All member pages (Dashboard, Performers, Token Packages, Account, Support) + all streamer pages  
**Devices:** Desktop Firefox  
**Error:** Generic `Error` — detail not captured by Playwright in Firefox  
**Detail:** Every logged-in page throws a JavaScript error in Firefox. Error messages were not captured at the detail level — needs manual investigation in Firefox DevTools.

---

## LOW Bugs

### BUG-7 — Small tap targets site-wide (mobile)
**Pages:** All pages  
**Devices:** iPhone 14 Pro, Samsung Galaxy S23  
**Detail:** Interactive elements (links, buttons, inputs) are below the 44×44px minimum tap target size recommended by Apple HIG and WCAG 2.5.5. Affects every page on both mobile devices.
